🚀 快速开始
═══════════════════════════════════════════════════════

1. 双击运行：run_compare_gui.bat

2. 选择文件：
   - 点击"选择输入视频" → 选择你的羽毛球训练视频
   - 点击"选择输出路径" → 指定输出文件名

3. 点击"开始处理"

4. 观察处理进度：
   ✓ 三个画面会实时更新（每10帧）
   ✓ 日志显示处理进度和FPS
   ✓ 完成后自动加载结果

5. 查看结果：
   - 点击"播放"按钮
   - 使用进度条定位到感兴趣的片段
   - 对比原始视频和标注结果

⚠️ 重要提示
═══════════════════════════════════════════════════════

音频功能需要：
  • ffmpeg（推荐）- 最快最稳定
    安装：choco install ffmpeg

  • 或 moviepy（备选）
    安装：pip install moviepy

处理过程中：
  • 三个画面会自动更新
  • 不要关闭窗口
  • 可以观察日志了解进度
  • 完成后会弹出提示

首次使用GPU：
  1. 运行 scripts\fix_gpu.bat
  2. 运行 scripts\test_gpu.bat 验证
  3. 确保显示"CUDA: True"

🎯 参数说明（4个标签页）
═══════════════════════════════════════════════════════

模型设置
  • 姿态模型：n=最快，m=平衡，l=最准
  • 置信度：0.25默认，越低越敏感
  • GPU：必须启用才能快速处理
  • FP16：减少显存占用

显示设置
  • 线条宽度：2默认，投影可用4
  • 关键点大小：4默认，看具体需求
  • 慢动作：1.0原速，0.5两倍慢
  • 视频质量：90推荐

颜色设置
  • 点击颜色块可以自定义
  • 建议使用对比度高的颜色
  • 教学场景推荐亮色

分析设置
  • AI分析：自动检测问题
  • 显示角度：显示关节角度
  • 显示问题：标出姿势错误
  • 保存关键帧：自动截图

🔍 故障排查
═══════════════════════════════════════════════════════

问题：处理很慢（<20 FPS）
解决：
  1. 运行 scripts\fix_gpu.bat
  2. 确认"使用GPU"已勾选
  3. 运行 test_gui_fixes.bat 检查环境

问题：没有声音
解决：
  1. 检查日志中的音频信息
  2. 安装ffmpeg或moviepy
  3. 运行 test_gui_fixes.bat 验证

问题：没有姿态标注
解决：
  1. 确保视频处理完成
  2. 检查"置信度"不要设太高
  3. 查看日志是否有错误

问题：看不到实时画面
解决：
  1. 确保在"开始处理"后观察
  2. 等待10帧后会首次更新
  3. 完成后点"播放"查看完整视频
