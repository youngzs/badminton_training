🎮 操作流程
═══════════════════════════════════════════════════════

方式1：处理新视频
  1. 选择输入视频
  2. 设置输出路径（可选）
  3. 调整参数（模型/显示/颜色/分析）
  4. 点击"开始处理"
  5. 等待处理完成
  6. 自动加载播放，查看分析结果

方式2：查看已处理视频
  1. 点击"📂 加载已处理视频"
  2. 选择之前处理的视频文件
  3. 系统自动加载原始视频和姿态数据
  4. 立即播放查看分析结果

播放控制：
  - ▶/⏸ 按钮：播放/暂停
  - 空格键：播放/暂停快捷键
  - ⏮ 重置：回到第1帧
  - 进度条：拖动跳转，播放时自动同步
  - 帧标签：显示"当前帧 / 总帧数"

⚙️ 技术规格
═══════════════════════════════════════════════════════

【系统要求】
  - Python 3.8+
  - CUDA 11.x+ （GPU加速）
  - 8GB+ RAM
  - NVIDIA RTX GPU（推荐）

【依赖库】
  - ultralytics（YOLOv8）
  - opencv-python（视频处理）
  - torch（深度学习）
  - tkinter（GUI）
  - Pillow（中文字体）
  - ffmpeg（音频复制，可选）
  - moviepy（音频备选，可选）

【性能】
  - GPU处理：30-60 FPS
  - CPU处理：5-15 FPS
  - 内存占用：2-4 GB
  - 视频质量：可调（0-100）

【模型】
  - 姿态检测：yolov8n-pose.pt / yolov8s-pose.pt / yolov8m-pose.pt
  - 装备检测：yolov8n.pt（使用COCO类别映射）
  - 自定义模型：支持

💡 使用建议
═══════════════════════════════════════════════════════

最佳实践：
  1. 首次使用建议使用yolov8n-pose（快速）
  2. RTX GPU用户启用FP16加速
  3. 保持默认文件命名规则（*_processed.mp4）
  4. 定期保存配置
  5. 使用空格键快速播放/暂停

性能优化：
  1. 降低视频分辨率可提高处理速度
  2. 调低置信度阈值可检测更多姿态
  3. GPU内存不足时使用yolov8n-pose
  4. 关闭不需要的显示元素

分析技巧：
  1. 使用慢动作查看细节（2-5x）
  2. 结合进度条精确定位关键帧
  3. 对比多次动作的姿态数据
  4. 保存关键帧便于后续分析
  5. 使用直接加载功能快速查看历史记录

═══════════════════════════════════════════════════════
🐛 已知问题和限制
═══════════════════════════════════════════════════════

限制：
  - COCO模型对羽毛球拍/羽毛球识别不够精确
    （使用tennis racket和sports ball近似）
  - 需要训练专用模型以提高装备检测准确度
  - 遮挡情况下姿态检测可能不准确
  - 多人场景可能影响检测效果

建议：
  - 拍摄时确保人物清晰可见
  - 避免严重遮挡
  - 光线充足的环境
  - 单人训练视频效果最佳
